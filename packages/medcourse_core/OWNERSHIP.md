# 谁能改什么（medcourse_core v0.2.1）

| 内容 | 谁写 | 伙计能不能改 |
|---|---|---|
| `medcourse/`（契约、抽取、统计、规划、编译、写手、闸门、流程、提示词） | 总经理 | 不能改。觉得要改，写进 GAPS，给出文件、行号 |
| `medcourse/data/`（公开 ICD 词典生成的两张表）、`tools/` | 总经理 | 不能改 |
| `tests/` | 总经理 | 不能改；可以另加自己的测试文件 |
| 批跑脚本、槽位和住院号文件、建表、打包 | 伙计 | 伙计自己写，放 `code/` |

发现代码有错时不要就地改：把出错的位置写进 GAPS，停用到它的步骤，其他步骤继续。契约、提示词改动都要升版。
