## 一次住院怎么读

1. `build_real(导出文件的一行)` 或 `build_synth(槽位, 文书列表)` → `Admission`。按 `(day_offset, 文书类型, 文书序号)` 排时间轴；`day_offset` 为空的、出院后才写的病程放进 `off_docs`，不参与任何先后判定。病程子类从正文前 300 字的标题词判断，取位置最靠前的一个（首次病程用 v0.5 的 `is_first_progress`）。
2. `core_set(adm)` → 核心集：入院记录、首次病程、第一篇上级医师查房、术前小结和术后首次病程（有手术时）、至多 3 篇其他病程（按住院天数的 1/4、2/4、3/4 处挑）、出院记录。缺入院记录、首次病程或出院记录返回 `None`。
3. `evaluate_admission(adm)` → 全部读数。硬冲突读数给出每个冲突两端的位置 `(文书序号, 起, 止)`，可以回指原文。

## 和 10-18 方案不同的地方

1. **文书抬头由程序写，不让模型写再解析。** 合成病历每篇的"第几天"直接取槽位骨架，模板里的日期由程序按虚构入院日推算；方案 2.1 的"【文书类型】【住院第 N 天】"解析不需要了。C3 改查"正文日期和出院记录抬头"。
2. **口吻优先级**：方案写"历史 > 计划 > 结果"。实际写法里"完善 CT、MRCP 等检查"和"复查 CT 示……"常在同一句，单纯按优先级会把结果判成计划。改成上一节的顺序：计划触发词必须在检查词之前、且中间没有结果词，才算计划。
3. **读数拆细**：S4 拆成 S4a（入路）、S4b（手术日）；新增 K5 未来日期、B4b、B5 两个带读数、K3s 诊断读数；C1 拆成 a、b、c 三个。
4. **五组**：在四组之外加 G-E（只控可见性、不给判断层，即 NHS 管线的做法），用来量判断层本身的增量。
5. **生成模型改用 Qwen2.5-32B-Instruct-AWQ**：关1 已说明 32B 是我们卡上最强的模型，生成侧结论应该用它；8B 降为可选的第三阶段（规模对照）。
6. **校6 改成日期一致性检查**：用户 10-20 决定不再连数据库，拿不到未脱敏版。改查"病程抬头日期 − 入院日期 = day_offset"的比例，以及只有年份的写法的数量；不达标时 K5、S4b 降为诊断。
7. 用药仍不进 v0.1（同方案）。

## 雷（校8）和合法差异（校9）

`g2_kit/mines.py`。十种雷：S1、S3、S4a、S4b、K1、K2、K3、K4、K5、B2。注入位置用本文件自己的规则挑，不调用关2 尺子的判定（S3 借用关1 v0.5 已定稿的侧别抽取，见 0.2 表；B2 从 0.3 起借用关2 的诊断词典认名字和状态，只管"尺子认不认得这个诊断"，不管有没有依据，见 0.3 表）；能用本住院自己的句子就用（mode=own），找不到才用固定模板句（mode=template）。`plant()` 不改原住院，返回新住院和 `MineRecord`（位置、方式）。七种合法差异 L1、L2、L3、L5、L6、L7、L8，各对应一个"不应新报冲突"的读数（`LEGIT_READING`）。

虚构病历上的结果（自检里固定下来）：三份病历上能埋的雷全部命中且定位正确；七种合法差异在能做的病历上都不新报硬冲突；内科病历上手术类雷一律埋不进去（返回 `None`），这是对的。

## 生成（`g2_kit/gen.py`）

- `make_slot()`：槽位 = 真实住院的属性 + 核心集骨架（每篇的类型和第几天）+ 程序算的虚构入院日（2025-01-01 加 `sha256(slot_id) % 300` 天）。
- `draft_messages()` / `validate_draft()`：事实底稿（最终诊断、入院表现、带日子的检查、带依据的判断变化、带日子的处置），程序逐条校验六条规则，不过就把错误清单发回重写。
- `doc_messages(arm, slot, k, prior, draft)`：五组的逐篇提示词。G-D、G-E 用 `render_visible()` 只给到当天为止已知的东西；G-C 给整份底稿；G-A 只给属性和出院主要诊断；G-B 再加日期、住院天数、文书安排和手术日。前文太长时先放下最早的非入院记录。
- `oracle_leaks()`：按底稿算的泄漏（只对 G-C、G-D、G-E）：O 未回报的检查结果被写出，A 未实施的手术操作被写成已做，B 还没确诊或排除的诊断被写成确诊或排除。这组读数和尺子无关，用来回应"按尺子的规则造病历再用尺子量"的质疑。

## 评委（`g2_kit/judge.py`）

QK（知识边界）、QS（状态接续）、QB（诊断轨迹）三条逐项问题，都是"直接问、给定义和例子、要引文"的最强问法；JH 是现有工作常用的"时间一致性打 1–5 分"。`paired()` 算成对检出和对评委有利、不利的上下界。

## 统计（`g2_kit/stats.py`）

Clopper–Pearson、按槽位整簇 bootstrap（1,000 次，种子 20261014）、配对差、带内判定、AUC、Kendall τ 及其 bootstrap 区间。只用标准库。
