# 谁能改什么（g2_core v0.4）

| 内容 | 谁写 | 伙计能不能改 |
|---|---|---|
| `ruler_g1/` | 关1 定稿 v0.5 | 不能改 |
| `ruler_g2/` 全部规则和词表（`config/exams.json`） | 总经理 | 不能改。觉得要改，写规则提案：哪条规则、哪类文书、多少次住院受影响（只给计数和位置），建议怎么改。总经理批准后升版本 |
| `g2_kit/mines.py`、`floors.py`、`diag.py` | 总经理 | 不能改 |
| `g2_kit/gen.py` 里的全部提示词、模板、底稿校验、可见性控制 | 总经理 | 不能改，逐字使用 |
| `g2_kit/judge.py` 里的全部提示词和解析 | 总经理 | 不能改，逐字使用 |
| `g2_kit/oracle2.py`、`ruler_g2/c2parts.py`、`ruler_g2/similarity.py`（0.4 新增） | 总经理 | 不能改 |
| `g2_kit/gen2.py` 里的全部提示词、状态表写法、时刻区间、覆盖检查、槽位过滤（0.4 新增） | 总经理 | 不能改，逐字使用 |
| `g2_kit/stats.py` | 总经理 | 不能改；需要别的统计量，在自己的脚本里写，并在 REPORT 里写明公式 |
| `tests/` | 总经理 | 不能改；可以另加自己的测试文件 |
| 批跑脚本、模型调用、断点续跑、建表、查看页面、打包 | 伙计 | 伙计自己写，放 `code/`，进包 |

发现代码有错（崩溃、明显写错）时：不要就地改。把出错的位置（文件、行号、住院号、文书序号、字符偏移）和报错类型写进 GAPS；能绕开的先绕开（跳过该住院并计数），绕不开就停下这一步，先做别的。
