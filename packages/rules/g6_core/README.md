## 0 这个包干什么

关卡谱关6 的问题：给定一个诊断，一批合成病历覆盖了真实病历里的非典型表现、少见合并症、少见处置吗，还是同一模板的若干变体？LLM-CARe 在这一关的状态是"失敏 + 自证循环"：它的知识覆盖（Knowledge Coverage，表 1 里 94.1）是拿参考集的实体逐字去匹配，而它的语料层（corpus stage）恰恰是按同一份参考集的实体清单往病历里加词。

这个包给任务书 Q6 提供五样东西：

| 模块 | 干什么 | 用在 |
|---|---|---|
| `q6_kit/entities.py` | 从 7 字段病历的四段叙述里抽五类实体（论文附录 A.5 的五类） | 全部 |
| `q6_kit/care_quota.py` | LLM-CARe 语料层 Critic 的逐行移植（配额、改写计划、反馈句），加"照单全收"地板 | 生成 S6、T6，地板 F-QOK |
| `q6_kit/kcov.py` | 知识覆盖（论文口径：字符串精确匹配） | H6-1 |
| `q6_kit/diversity.py` | 同诊断内两两 Jaccard、Self-BLEU、Vendi、年龄等单项分布、等长截断 | H6-3 |
| `q6_kit/tail.py` | 不典型实体、"指向一个真人"的实体组合、抄写比例 | H6-4、H6-5 |
| `q6_kit/b6.py` | 语料层插进来的词和本来就有的词，各自查冲突、查细节 | H6-2 |
| `q6_kit/split.py`、`mask.py` | 事先定死的分组抽样；进包前打码 | 全部 |

## 1 实体尺子 `entities.py`（g6-rules-0.1）

LLM-CARe 没公开它怎么从真实病历里抽实体（论文只说"从真实病历里抽取每个诊断相关的医学实体"，公开的参考文件里实体是现成的）。这里用规则代替，全部是词表加少量开放后缀，没有看任何真实病历：

| 类别 | 论文的类 | 怎么认 |
|---|---|---|
| SYM 症状体征 | Symptom | 关4 尺子的症状词表（去掉"疼痛""瞳孔""肌力"一类不成症状的词） |
| AUX 辅助检查 | Auxiliary Examination | 关4 检查词表里的影像、心电、内镜、功能检查，加补充词；开放后缀"……CT/CTA/MRI/彩超/B超/超声/平片/X线/造影" |
| LAB 实验室检查 | Laboratory Examination | 关4 检查词表里的化验，加补充词；开放后缀"……常规/培养/测定/定量/抗体/抗原/核酸/全套/五项" |
| SURG 手术与操作 | Surgery | 开放后缀"……术"（往前截到动词、虚词为止，"建议患者接受手术""第二次手术"一类不算）；有名字的侵入性操作和非药物治疗（PCI、ERCP、透析、化疗、吸氧……） |
| MED 药物 | Medication | `ruler_g3` 药名词表（280 个药，"肝素帽"一类不算）；带剂型的写成整个产品名（"阿司匹林肠溶片"），键仍是药名 id；词表外的维生素等；开放剂型后缀"……片/胶囊/注射液/颗粒……"（"胸片""每次2片"不算） |

- 同一处只算一类：药名词表最先；其余词表和开放后缀同一级，长的优先（"前列腺彩超"胜过"彩超"）。
- 否定：实体前面同一分句 8 字内有"无、否认、未诉、不伴、未见、未出现、未再、未有、没有、未、拒绝"，记 `neg=1`（只对症状和手术操作；药用 `ruler_g3` 自己的否定判断）。
- 含"医院、卫生院、诊所、中心、门诊、省市县区镇乡村街道社区"或数字的一律不当实体（守则 1.2）。
- 两种写法：`surface`（原文写法，知识覆盖用，与 LLM-CARe 一样逐字匹配）和 `key`（规范键：药是药名 id，其余是 NFKC 小写，多样性和长尾用）。
- **参考集只收没被否定的**（`ref_entity`）：公开的 example-ref.jsonl 里"No significant dizziness, headache"这类否定的症状不在实体表里。知识覆盖的匹配照论文是子串匹配，合成病历写"无头痛"也会匹配上"头痛"（对 LLM-CARe 有利，不改）。

## 2 语料层配额 `care_quota.py`

### 2.1 逐行移植

照抄 `official/llmcare.py` 的 `_load_ref`、`allocate_samples`、`_get_corpus_statistic`、`_extract_feature`、`_corpus_critic`，只改四处，都不碰配额逻辑：

| 编号 | 原代码 | 这里 | 为什么 |
|---|---|---|---|
| A1 | 全局 `random` | 传进一个 `random.Random`（`round_rng(行, 诊断, 轮次)`，字符串种子） | 可复现 |
| A2 | `_load_ref` 用 `set(...)` 往 Counter 里加实体，先后由字符串哈希种子决定 | 每份参考病历的实体按写法排序后加；参考病历由调用方按住院号排好 | 打平时选谁、候选词先后不再随哈希种子变 |
| A3 | 反馈句 `"、".join(一个 set)` | 按写法排序后再连 | 同上；句子原文不变（"Add the following keywords："是全角冒号，原代码如此） |
| A4 | 性别只认英文 male、female | "男"当 male、"女"当 female，先判 male 后判 female，与原代码同序 | 我们的病历写中文 |

年龄照原代码读 `patient_info` 里第一个整数（"8个月"当 8 岁，不改）。自检 `test_corpus_critic_same_as_official` 用 AST 从原件里取出这五个方法、一个字不改装进壳子，与本移植在 300 组编造输入上逐条比反馈（同一个种子）：性别年龄句逐字相同，加词、删词的词集合相同。

### 2.2 原代码算式的问题（照抄、不修；另给修正版只作对照）

实体字段的期望份数是 `allocate_samples(ref[段], round(n × S))`：`ref[段]` 是每个实体在参考病历里的出现比例 p，S = Σp（参考病历这一段平均有几个不同的实体）。`allocate_samples` 是给"加起来等于 1 的分布"写的，这里没先除以 S，于是**每个实体的期望份数 = n × S × p，是按真实比例（n × p）的 S 倍**。用公开的 example-ref.jsonl 自己就能看出来：I63.900 只有 1 份参考病历，出院医嘱一段 7 个药，3 份初稿时每个药"应该"出现 21 份（自检 `test_inflation_official_example`）。

后果：几乎每个参考实体都"不够"，Critic 几乎只加词、不删词；最缺的是常见词，所以加进去的多是常见词。这不是"把分布对齐"，是"把参考词表往每一份里塞"。

`corpus_critic(..., corrected=True)` 先除以 S（期望份数 = n × p）。**LLM-CARe 的各行一律用原样**；修正版只给地板 F-QOKc 用，回答"病历变得更像，是这个算式造成的，还是配额这个思路本身"。

### 2.3 我们自己加的

- `to_internal`、`from_internal`：7 字段与 LLM-CARe 内部格式互转（`to_internal` 与关1 G1-D 伙计代码 `g1d_reviser_replay.to_internal` 逐字相同）。
- `apply_demog`：性别、年龄按改写计划直接写回（同关1 G1-E `apply_plan`：年龄写整数字符串）。原代码是让 Reviser 只改 `patient_info` 一栏，听话时结果相同；直接写回省掉这部分模型噪声，关1 已经量过它。
- `apply_ideal`、`run_ideal`：地板 **F-QOK"配额照单全收"**：一个完全听话、但只会抄词的 Reviser。要删的词从该段删掉，要加的词在该段末尾加一句"词1、词2。"。两轮，每轮重新跑 Critic。
- `parse_keywords`：反馈句 → 词集合；`expected_per_entity`：每个参考实体的期望份数（R6-0 描述用）。

## 3 知识覆盖 `kcov.py`

论文原话："we first extract medical entities associated with each diagnosis from the real EMRs. We then measure the proportion of these entities that appear in synthetic EMRs with the same diagnosis … we use exact string-level matching"。没写是整批算还是逐份算、加不加权。这里：

- `ref_vocab(参考病历)`：{(类别, 写法): 出现在几份参考病历里}；
- `kcov(池, 词表)`：词表条目在池里**任何一份**四段叙述里作为子串出现过就算覆盖，覆盖条数 ÷ 词表条数（主口径，不加权）；`weighted=True` 按参考份数加权；五类合起来是 `all`，每类另给；
- `kcov_per_record`：逐份算"词表里有多少比例出现在这一份里"再平均（论文的另一种可能读法，另报）；
- `gain_attribution`：语料层前后新覆盖的条目里，有几条是 Critic 点名要加的。

K-COV 依赖池的份数和长短，所以只在份数相同的池之间比（任务书里是每池 15 份）。

## 4 多样性 `diversity.py`

全部在同一个三位码之内算，再对诊断等权平均：

- `within_code_jaccard`：两两 Jaccard（`entities.key_set`，没被否定的实体规范键）——H6-3 主读数；
- `self_bleu`：字符级 BLEU-4（n>1 加一平滑，短句惩罚取最接近的参考长度），每份对同组其余各份；
- `vendi`：字符 1–3 元 TF-IDF 余弦核的 Vendi 分数（Friedman & Dieng 2023），返回（÷份数, 原值）；TF-IDF 在要比的几行合起来的文字上拟合；
- `profile`：不同值个数、熵、众数占比（年龄、性别、最高体温……）；`max_temp`：主诉和现病史里的最高体温；
- `truncate_pair`：两份病历四段各自去掉方括号占位符和空白后截到较短那份的长度（保留原文，好抽实体）；
- `strat_boot`：每个诊断内有放回重抽槽位的分层 bootstrap（1,000 次，种子 20261014）；`mean_pairwise` 不把同一份抽两次的配成一对。

## 5 长尾 `tail.py`

- `atypical_items`：一份病历里"不典型"的实体 = 在同诊断其他真实病人里份数 ≤ 门槛（max(1, ⌊0.05 × 其他人数⌋)），但 fold 0 别的真实病人写过；fold 0 里谁都没写过的记"孤词"，两边都单独报。真实病历算自己时从两张份数表里减掉自己（留一）。
- `unique_combo`：合成病历与某个参考病人共有 ≥3 个实体，且 fold 0 里同时有这几个实体的只有这一个人，记"指向一个真人"。`build_index`、`holders` 是倒排索引。
- `copy_share`：合成病历含了某一个真人实体清单的最大比例；`real_real_copy_share`：真人对同诊断其他真人的同一读数（留一），当基线。

## 6 插词冲突 `b6.py`（H6-2）

同一份语料层之后的病历里比：`label_mentions(前, 后)` 把每处实体标成"插进来的"（落在逐段比对新插入或换掉的文字里，且语料层之前这一段没有这个写法）或"本来就有的"；`conflicts` 用同一套规则查：

| 规则 | 什么算 |
|---|---|
| DRUG | `ruler_g3` 药物规则（年龄、妊娠、性别，g3-rules-0.2 原样）命中这一处药名 |
| SEX-ENT | 只属于男性的（前列腺、睾丸、阴囊、精索、包皮、阴茎）写在女性病历里，或只属于女性的（子宫、卵巢、阴道、宫颈、输卵管、附件、妊娠、孕、月经、产后、剖宫产、绝经、妇科）写在男性病历里 |
| PED-ADULT | 14 岁以下写了冠脉造影、PCI、PTCA、CABG、冠脉支架、支架植入、前列腺、绝经、剖宫产、妊娠 |
| NEG-X（只计数） | 这一处是肯定的，同一份病历另一段把同一个实体否定了；可能是病程前后的正常变化，总经理逐条读 |

`summarize` 给两类各自的实体数、主规则冲突数、NEG-X 数，以及检查有结果（关4 尺子口径）、药有剂量（`ruler_g3` 口径）的分子分母。

## 7 分组和打码

- `split.split_hold_ref`：fold 0 份数 ≥30 的头部诊断，真实病人随机分出 15 人当 HOLD（H6-1 的真人对照），其余当 REF（配额和知识覆盖的参考）；不足 30 的不分。`halves`：同诊断的合成病历分两半（每半 15 份）。种子都是字符串，输入先排序。
- `split.pick_tail`：长尾诊断 = 全部 fold 合计 ≤10 次住院、fold 0 里至少 1 次截得出 7 字段、不是关1 的 10 个头部诊断；多于 40 个随机取 40 个。**10 份这条线是 LLM-CARe 自己的剔除线按比例换算的**：它在 71 万份里剔掉不足 500 份的诊断，500 ÷ 710,000 × 15,192 ≈ 10.7。`tail_alias` 给代号 TAIL01…，进包的表只用代号。
- `mask`：语料层之后的病历和反馈句里，fold 0 份数 <20、或长于 10 字、或像地名机构名的词换成【词:类别:n字】；长尾病名换成【病名:n字】；`leak_count` 打码后核对必须为 0。

## 8 已知的取舍

- 实体尺子是在合成病历上补的词（没看真实病历）。真实病历写法更杂，尺子在真实一侧漏得更多：真实病历的实体会少算。对 H6-3（真实被少算 → 真实的两两 Jaccard 会怎样变不确定）和 H6-4（真实被少算 → 真实的不典型率偏低，对"合成更少不典型"是保守的）影响方向不同，任务书要求报真实一侧每份实体数，并给可选的用户标注页看尺子在真实病历上的精确率。
- 知识覆盖照论文用子串匹配，"头痛"会匹配"无头痛"，短写法（"CT"）会匹配一切含它的写法。对两边一样。
- 唯一组合只在 fold 0 里查（不读其他 fold 的正文），"fold 0 里唯一"比"全库唯一"容易，读数偏高；T6 和 T1 同样受影响，所以主判用 T6 − T1。
- 配额移植跑的是原代码的 Critic；Adviser、Reviser 用关1 G1-D v1.5 修好的那一版（伙计代码，8B），提示词同公开代码。性别、年龄直接写回，见 2.3。
