## v0.5 相对 v0.4 的改动（2026-10-19，依据 Panyto 第 1 轮 205 条标注里看到的误报）

只动了 G1-4、G1-5、G1-6；G1-1～G1-3 的行为不变。规则号 g1-rules-0.5。

**G1-4（起病时长）改为"证据口径"，原 G1-4b 并入，不再单列。** 输出里不再有 `G1-4b` 这个键，读 `checkable`、`conflicts` 的代码请用 `.get()`。

1. 归一：认"30余年""3个多月"（余/多在单位前）、"7+年"、"1年半"；"孕36周""孕38+2周""停经N周"不再当病程。
2. 主诉病程：取主诉里最长的一段，但写"加重/再发"的段不算病程；主诉里"于1周前入院"的时长不算病程。多段主诉的最长段（如"发现血压升高10年"）在现病史里既没有同样长的证据、带时长的句子也没提到它的症状时，改比下一段（"头晕3天"）。
3. 现病史证据：任何"N…前"、"入院前N天"、"近N月"、"今晨/昨日"＋起病动词、"2024年1月出现…"（用入院日期换算，只有日期能读出来时才用）、不带"前"的病史时长（"高血压病史10年"）。每条证据带类别：
   - `kind=onset` 起病；`kind=hist` 病史时长或治疗事件（"30年前行甲状腺手术"），只能帮着判相容，不能单独让这一对可比；
   - `kind=worse` 加重（"3天前症状加重"），只在主诉本身写的是加重时长时才参与；
   - `dx=1` 证据所在分句是确诊、发现类事件。
4. 判定：至少有一条 `kind=onset` 证据才可比；任何一条证据与主诉病程相容就不冲突。主诉从确诊、发现、治疗起算（`anchor=1`）或写的是加重时长时，比它更早的起病证据也算相容，但 `dx=1` 和病史时长不参与这一放宽。另外，加重段比整个病程还长且现病史没有证据对得上时，也报冲突。
5. 事实字段：`chief_duration` 的值多了 `|anchor=0/1|worse=0/1`；`onset_any` 的值多了 `|kind=…|dx=0/1`；新增 `onset_date`（`YYYY-MM-DD|prec=day/month|kind=…|dx=…`）。`onset_ago`（现病史第一个"N…前"）保留，只作展示。

**G1-5（侧别）**

6. 阴性所见（"右侧卵巢未见异常""左肺未闻及啰音"）里的侧别不比。
7. "左锁骨中线"这类体表定位线不算病变部位。
8. 修 v0.4 的错：现病史第一句的分句会越过"现病史："标题，标题里的"病史"两字让第一句的侧别全被当成既往。v0.5 分句不越过段落边界，所以现病史第一句的侧别会重新参与比较。
9. 两侧可以各有一处病灶的部位（颈动脉、椎动脉、大脑中动脉、基底节、额叶等，见 `config/organs.json` 的 `_multi`）不比。

**G1-6（住院天数）**

10. 当天入出院记 1 天不算冲突（实际差 0、记 1）；记 2 天仍算冲突。
