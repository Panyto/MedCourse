# 谁能改什么（g3_core v0.2）

| 内容 | 谁写 | 伙计能不能改 |
|---|---|---|
| `ruler_g3/` 全部代码和 `data/` 下四张表（词表、规则表、剂量表、出处表） | 总经理 | 不能改。觉得要改，写规则提案：哪条规则、哪个药、哪类文书、多少次住院受影响（只给计数和位置），建议怎么改。总经理批准后升版本 |
| `q3_kit/mines.py`、`floors.py` | 总经理 | 不能改 |
| `q3_kit/judge.py` 里的提示词、标准原文、解析、采样参数，`q3_kit/render7.py` | 总经理（照抄关1 冻结代码和 LLM-CARe 公开代码） | 不能改，逐字使用 |
| `q3_kit/stats.py` | 总经理（照抄 g2_core 0.4） | 不能改；需要别的统计量，在自己的脚本里写，并在 REPORT 里写明公式 |
| `tests/` | 总经理 | 不能改；可以另加自己的测试文件 |
| 批跑脚本、配额改写重建、模型调用、断点续跑、建表、查看页面、打包 | 伙计 | 伙计自己写，放 `code/`，进包 |

发现代码有错（崩溃、明显写错）时：不要就地改。把出错的位置（文件、行号、住院号或槽位号、文书序号、字符偏移）和报错类型写进 GAPS；能绕开的先绕开（跳过该病历并计数），绕不开就停下这一步，先做别的。
