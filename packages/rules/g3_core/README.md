## 尺子测什么

只查有白纸黑字出处、不看具体病情也成立的硬错误。不判"这个药该不该用""诊断对不对"（没有医生）。

| 读数 | 内容 | 进"硬错误"（D-hard）吗 |
|---|---|---|
| 年龄禁忌（AGE） | 左氧氟沙星 <18 岁、尼美舒利 <12 岁、可待因 <12 岁、曲马多单方 <12 岁 | 进，严重 |
| 妊娠禁忌（PREG） | ACEI、ARB、沙库巴曲缬沙坦、异维 A 酸、左氧氟沙星，用于诊断里写着妊娠、且没分娩没流产的女性 | 进，严重 |
| 剂量越界（DOSE） | 23 种常用药：6 岁及以上（或年龄不明）比成人最大日剂量；6 岁以下比"儿童最大 mg/kg/日 × 同龄男童体重中位数"再封顶，体重按年龄上限取（"2岁"按 3 岁，14.3 kg）。比值 >1.5 轻微，≥2 严重 | 进（轻微和严重都进） |

| 性别（SEX） | 男性用缩宫素、卡前列素、米非司酮（轻微）；女性用度他雄胺（警示级） | 不进，另报 |
| 警示级（warning） | 其他全身用氟喹诺酮 <18 岁、四环素类 <8 岁、女性用度他雄胺 | 不进，另报 |
| N1 不可能数值 | 体温 <25 或 >45℃；脉搏、心率 <10 或 >300；呼吸 <3 或 >100；收缩压 <30 或 >300、舒张压 >200、收缩压 ≤ 舒张压；血钾 <1 或 >12；血钠 <90 或 >200；血红蛋白 <15 或 >260 g/L；白细胞 >1000×10⁹/L；血糖 <0.5 或 >150；肌酐 >5000 μmol/L。值为 0 不算 | 不进，另报 |

## 怎么读一份病历

- `adapters.from_care7(record)`：LLM-CARe 的 7 字段病历（英文键或中文键）。主诉、现病史、住院经过、出院医嘱四段，年龄性别取字段，诊断取"出院诊断"字段。
- 年龄：`parse.parse_age_range` 给出下限和上限。整岁、整月、整周按区间（"2岁"是 2–3，"8个月"是 8/12–9/12，Age 栏只有数字"2"按岁算），写到天或带小数的上下限相同。`Record.age` 是下限，`Record.age_hi` 是上限。
- `adapters.from_admission(adm)`：整次住院（run 9 导出、关2 和 G3 的合成住院）。年龄性别取入院记录前 400 字的抬头，诊断取各篇的诊断段。
- 药名：`data/drug_lexicon.csv`，280 个药、389 个别名，最长别名优先；容易误配的商品名（可定、安定、美平、阿乐、代文等）不收。
- 一处药名算不算数：
  - 分句前面有否认、过敏、禁用、慎用、家属称谓，或药名后 6 字内有过敏、禁用、慎用、皮试：算"否定"，不判任何规则；
  - 药名后 12 字内有滴眼、眼膏、乳膏、外用、栓等，或前面紧挨外用、局部、滴眼：算"外用"，不判全身用药规则和剂量；
  - 分句里有停用、换用、改为一类字样：不判妊娠规则；
  - "肝素帽""胰岛素抵抗"一类不算药。
- 剂量：药名后到分句末、下一个药名或 40 字为止。认 mg、g、μg 和中文单位；"/kg""/ml""/h"一类不认；"0.25g×24粒 2粒 tid"算单次 0.5g；"每日总量""/日""/晚"算日剂量；频次先在剂量后 20 字内找，找不到再看药名和剂量之间。药名和剂量之间有顿号、并列词，或者逗号后面是另一个药的剂型字（"阿托伐他汀，复方丹参滴丸270mg"），剂量归后面那个药，不抽。
- 妊娠：诊断里有妊娠、孕 N 周、G?P? 一类字样；诊断和住院经过、出院医嘱（整次住院时是病程和出院记录）里没有分娩、剖宫产、流产（先兆流产除外）、终止妊娠等；非男性，10–60 岁。

## 已知的取舍（都偏向"宁可漏，不可错"）

- 剂量上限取说明书里最宽的方案（例如阿莫西林儿童取 90 mg/kg/日，头孢呋辛取脑膜炎量）。代价：2 岁用阿莫西林 0.5g tid（比值 1.17）不报。
- 体重用男童中位数，女童同龄更轻，所以对女童更宽；整岁按上一岁取体重（"2岁"按 3 岁），所以对刚满 2 岁的更宽。
- 只写了单次量、没写频次的，用单次量比每日最大量。
- 只做上限，不做下限，不做肾功能调整，不分口服和静脉。
- 年龄 6 岁及以上的儿童用成人最大量判，不按体重。
- 阿莫西林克拉维酸写的量可能含克拉维酸（最多多出 25%）。
- 其他氟喹诺酮和四环素类只核到"儿童有效性未确立"或"牙齿变色"，所以只作警示级。
