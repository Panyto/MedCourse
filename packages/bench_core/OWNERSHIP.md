# 谁能改什么（bench_core v0.2）

| 内容 | 谁写 | 伙计能不能改 |
|---|---|---|
| `bench/`（读数、注册表、负对照、锚点、三个小实验、探针） | 总经理 | 不能改。觉得要改，写进 GAPS，给出文件、行号、住院号或行名 |
| `data/anchors.csv`（门线容差和归档定稿数字） | 总经理（`tools/make_anchors.py` 从计数表生成） | 不能改 |
| `tests/` | 总经理 | 不能改；可以另加自己的测试文件 |
| 批跑脚本、`rows_S0.json`、D0 诊断码表、建表、打包 | 伙计 | 伙计自己写，放 `code/` |

发现代码有错（崩溃、明显写错）时：不要就地改。把出错的位置写进 GAPS，停用到它的步骤，其他步骤继续。

门线和指标定义在 S0 封存后只能升版改，升版要写明改了什么、为什么。
